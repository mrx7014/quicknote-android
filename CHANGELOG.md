# Changelog

## 1.4.0

- Added full item details and editing, persistent drafts, multiple tags, pin/archive/Trash, Undo, search and sort improvements.
- Hardened app-lock behavior, authentication recovery, external-picker returns, and sensitive-content accessibility.
- Moved notification confirmations to one dismissible inbox item; preserved reminders and added overdue digests.
- Improved voice recording cleanup and on-device transcription language selection, progress, cancellation, and lifecycle cleanup.
- Added Android 16/API 36 support, edge-to-edge insets, adaptive app icons, richer widgets, and dedicated Quick Settings tiles.
- Hardened backup validation and free-space checks; added unit tests for ZIP paths and tag normalization.
- Updated GitHub Actions to run wrapper validation, lint, unit tests, and clearly label signed versus unsigned artifacts.
